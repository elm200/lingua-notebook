# Lingua Notebook

AIチャットサービス(ChatGPT・Geminiなど)に貼り付けるプロンプトを生成し、その回答(JSON)を貼り付けて保存する、多言語対応の語学学習ウェブアプリ。

**デモ**: https://lingua-notebook.vercel.app

<img src="docs/screenshot.png" alt="Lingua Notebook スクリーンショット" width="480">


## 主な機能

- 学習対象言語を10言語(英語・中国語・韓国語・スペイン語・タイ語・ベトナム語・フランス語・ドイツ語・イタリア語・インドネシア語)から選択。選択はlocalStorageに保存され、リロードしても維持される
- 「プロンプトを生成してコピー」ボタンで、テーマ(100種)×文章の形式(10種)をランダムに組み合わせた、10件分のテキストをまとめて作成させるプロンプトを生成しクリップボードにコピーする
- 生成したプロンプトをAIチャットサービスに貼り付けて実行し、返ってきたJSONをアプリのテキストエリアに貼り付けると、10件のテキストと文ごとの解説がまとめて履歴に保存される
- 履歴(テキスト一覧)画面で過去に生成した文章を一覧・全文検索できる
- 単語帳: 気になった単語を登録すると、常に「最近登録した単語」として一覧の先頭に来る(同じ単語の再登録は削除→新規登録で最新化する設計)
- 単語から、その単語が登場する過去の文章を検索する画面
- すべてのデータは学習対象言語ごとに区分してlocalStorageに保存される。サーバー側の永続化は行わない

## 技術スタック

- フレームワークなし: `public/`に素のHTML/CSS/バニラJS、というシンプルな静的サイト構成(サーバー側API・DBは一切なし)
- ランタイム依存ライブラリなし
- `.js` + JSDoc(TypeScriptは未使用、`tsconfig.json` の `checkJs` で型チェック)
- テストは `node:test` のみ
- ストレージは `localStorage`(ブラウザごとに独立。サーバー側の永続化なし)

## セットアップ

### 前提

- Node.js

### 手順

```bash
npm install
```

ローカルではただの静的サイトなので、`public/`ディレクトリを任意の静的サーバーで確認できる。例:

```bash
npx serve public
# または
python3 -m http.server 8000 --directory public
```

Vercelにリンクしていれば `vercel dev` でも起動できる(API Functionsは無いため実質的に静的配信のみ)。

### テスト・型チェック

```bash
npm test          # node:test でユニットテスト実行
npm run typecheck # tsc --noEmit
```

## デプロイ

APIキーや環境変数を一切必要としない静的サイトなので、Vercelに `vercel deploy` するだけでよい。実際に配信されるのは `public/` ディレクトリのみで(`vercel.json` の `outputDirectory` で指定)、テストコードや設定ファイルなど非配信のファイルは `.vercelignore` でアップロード対象からも除外している。

## 使い方

1. ヘッダーの言語セレクタで学習対象言語を選ぶ。
2. トップページで「プロンプトを生成してコピー」を押す。テーマ・文章の形式がランダムに10件分決まり、プロンプトがクリップボードにコピーされる。
3. ChatGPTやGeminiなど、お使いのAIチャットサービスにプロンプトを貼り付けて実行する。
4. AIチャットが返したJSON全体をアプリのテキストエリアに貼り付け、「保存する」を押す。10件のテキストと解説が履歴に保存される。
5. 「テキスト一覧」画面で過去に生成した文章を閲覧・検索できる。文章中の単語をタップすると単語帳に登録できる。単語帳画面では登録した単語からその単語を含む文章を検索できる。

## AIチャットへの依頼内容について

生成されるプロンプトは、対象言語の教師として中級学習者向けの教材を作るよう指示し、以下を厳守させる:

- 本文・原文(`title`・`text`・`sentences[].text`)は必ず学習対象言語で書く
- 訳文・文法解説・語句の意味(`translation`・`grammar`・`vocab[].meaning`)は必ず日本語で書く
- 出力はコードブロックや説明文を含まないJSON形式のみ
- 語句解説(vocab)は「対象言語の単語をそのまま意味欄に書く」ことを禁止し、文法解説は単語の逐語訳ではなくパターン→意味→用法を説明させる

貼り付けられたJSONの形式(`lessons`配列、または配列そのもの)が想定と異なる場合や、依頼した10件と件数が食い違う場合はエラー・警告として画面に表示される(`public/js/promptBuilder.js`)。
